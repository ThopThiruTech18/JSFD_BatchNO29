If we want to iterate the data multiple times we can use for loop.
If we having fixed amount of data

-------

			{
			//statement...
			}

---------
		int start = 1;
		int end = 100000;

		for (int i = start; i <= end; i++) {
			System.out.println(i + " : Welcom to hyderabad");
		}
		
while loop:
------------
If we wants to iterate the data multiple time we can use the while loop
If we dont know no of iterations that you want to execute at the time we can use while loop


syntax:
		while(condition)
		{
		 //statements
		 
		  incre/decrement;
		}
Example:
-------
		int start1 = 1;
		int end1 = 10;

		while (start1 >= end1) {
			System.out.println(start1 + " : Welcom to hyderabad");
			start1++;
		}
		
		
do-while loop:
------------
If we wants to iterate the data multiple time swe can use the do-while loop
If we dont know no of iterations that you want to execute at the time we can use do-while loop


syntax:
		do
		{
		 //statements
		 
		  incre/decrement;
		}
		while(condition);
		
Example:
		int start = 1;
		int end = 10;

		do {
			System.out.println(start + " : Welcom to hyderabad");
			start++;
		} while (start >= end);
